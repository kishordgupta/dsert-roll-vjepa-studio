How this experiment works

Each new job exports stereo RGB PNGs, two event NPZ streams, stereo non-radiometric thermal PNGs, Livox and Ouster LiDAR arrays, and radar arrays. A common frame manifest links every file to the original timestamp. Calibration is scaled for the exported RGB resolution; recorded poses are included.

V-JEPA 2.1 encodes 16 frames from all nine generated sensor visualizations. It has no raw-sensor or text-to-video decoder. Weather/noise models generate these research augmentations; they do not form a physically calibrated multisensor simulator. The ZIP documents units, source hashes, model parameters and limitations.
